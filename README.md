# 1次元拡散方程式の数値解法

このリポジトリでは、1次元拡散方程式の数値解を陽的差分法（前進オイラー法）を用いて求め、理論解（解析解）と比較するプログラムを実装しています。

## 問題設定

### 偏微分方程式
∂u/∂t = ∂²u/∂x²  
ただし、0 < x < 1、t > 0

### 初期条件
u(x, 0) =
- 2x（x < 0.5）
- 2(1 - x)（x ≥ 0.5）

### 境界条件
u(0, t) = u(1, t) = 0

### 数値条件
- Δx = 0.1
- Δt = 0.002

## 実装内容

- `diffusion_equation.py`: 1次元拡散方程式を陽的差分法で解き、理論解と比較するPythonスクリプト

## 使用方法

以下のコマンドでプログラムを実行します：

```bash
python diffusion_equation.py
```

実行すると、以下の処理が行われます：

1. 時刻 t = 0, 0.05, 0.1, 0.2, 0.4 における数値解と理論解が計算されます
2. 計算結果が表形式で表示されます
3. 数値データと理論解がCSVファイル `diffusion_equation_results.csv` として保存されます
4. 数値解と理論解を比較したグラフが表示され、`diffusion_equation_solution.png` として保存されます

## 数値解法について

### 陽的差分法（数値解）
陽的差分法では、以下の差分近似を用いています：

- 時間微分: ∂u/∂t ≈ (u(x, t+Δt) - u(x, t)) / Δt
- 空間微分: ∂²u/∂x² ≈ (u(x+Δx, t) - 2u(x, t) + u(x-Δx, t)) / (Δx)²

これにより、次の時間ステップの値は以下の式で計算されます：

u(x, t+Δt) = u(x, t) + r * (u(x+Δx, t) - 2u(x, t) + u(x-Δx, t))

ここで、r = Δt/(Δx)² は安定性パラメータであり、陽的差分法の安定条件 r ≤ 0.5 を満たす必要があります。

### 理論解（解析解）
1次元拡散方程式の理論解は、フーリエ級数展開を用いて以下のように表されます：

u(x, t) = Σ bn * sin(nπx) * exp(-(nπ)²t)

ここで、bn はフーリエ係数であり、初期条件から計算されます。この問題の場合：

bn = 8/(nπ)² * sin(nπ/2)

プログラムでは、n = 100 までの項を計算して理論解を求めています。

## 必要なライブラリ

- NumPy: 数値計算
- Matplotlib: グラフ描画
- pandas: データフレーム操作とCSV出力

## 注意点

- 陽的差分法は、安定性条件 Δt/(Δx)² ≤ 0.5 を満たす必要があります。この条件を満たさない場合、数値解が発散する可能性があります。
- 理論解はフーリエ級数の有限項で近似しているため、特に初期時刻付近では完全に正確ではありません。項数を増やすことでより精度の高い解が得られます。
