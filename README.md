# 1次元拡散方程式の数値解法

このリポジトリでは、1次元拡散方程式の数値解を陽的差分法（前進オイラー法）を用いて求めるプログラムを実装しています。

## 問題設定

### 偏微分方程式
∂u/∂t = ∂²u/∂x²  
ただし、0 < x < 1、t > 0

### 初期条件
u(x, 0) =
- 2x（x < 0.5）
- 2(1 - x)（x ≥ 0.5）

### 境界条件
u(0, t) = u(1, t) = 0

### 数値条件
- Δx = 0.1
- Δt = 0.002

## 実装内容

- `diffusion_equation.py`: 1次元拡散方程式を陽的差分法で解くPythonスクリプト

## 使用方法

以下のコマンドでプログラムを実行します：

```bash
python diffusion_equation.py
```

実行すると、時刻 t = 0, 0.05, 0.1, 0.2, 0.4 における解のグラフが表示され、`diffusion_equation_solution.png`として保存されます。

## 数値解法について

陽的差分法では、以下の差分近似を用いています：

- 時間微分: ∂u/∂t ≈ (u(x, t+Δt) - u(x, t)) / Δt
- 空間微分: ∂²u/∂x² ≈ (u(x+Δx, t) - 2u(x, t) + u(x-Δx, t)) / (Δx)²

これにより、次の時間ステップの値は以下の式で計算されます：

u(x, t+Δt) = u(x, t) + r * (u(x+Δx, t) - 2u(x, t) + u(x-Δx, t))

ここで、r = Δt/(Δx)² は安定性パラメータであり、陽的差分法の安定条件 r ≤ 0.5 を満たす必要があります。

## 必要なライブラリ

- NumPy
- Matplotlib

## 注意点

陽的差分法は、安定性条件 Δt/(Δx)² ≤ 0.5 を満たす必要があります。この条件を満たさない場合、数値解が発散する可能性があります。
